# NetBench CLI

Надежная CLI-утилита на Node.js и TypeScript (`strict`-режим) для замера пропускной способности интернет-соединения с интерактивным Zero-Flicker TUI на базе дифференциального рендеринга.

## Основные возможности

- **10 последовательных HTTP(S) GET-запросов** к целевому ресурсу с потоковым вычитыванием (`stream consumption`) без буферизации всего тела ответа в оперативной памяти (защита от OOM на тяжелых файлах).
- **Точный замер времени** с использованием `node:perf_hooks` (`performance.now()`).
- **Интерактивное fallback-меню** при запуске без аргументов: пресеты из `config/presets.json`, ввод произвольного URL с валидацией протокола/формата и переключение языка (`RU` / `EN`).
- **Zero-Flicker TUI:** двойная буферизация (`ScreenBuffer` + `DiffRenderer`) с посимвольным/построчным диффингом и точечным обновлением экрана через ANSI-последовательности без мерцания и без `console.log` / `console.clear`.
- **Отказоустойчивость:**
  - Для `HTTP 429`: приоритетный учет заголовка `Retry-After` (секунды или HTTP-date) и `Exponential Backoff` с jitter.
  - Для прочих `4xx`/`5xx` и сетевых сбоев (`ETIMEDOUT`, `ECONNRESET`, `ENOTFOUND` и др.): ограниченное число повторов с паузой и корректный возврат информативной ошибки без падения процесса.
  - **Global Error Boundary:** перехват всех необработанных исключений с выводом локализованного сообщения (stack trace доступен только с флагом `--debug`).

## Запуск

### 1. Интерактивный режим (fallback-меню)

Запустите утилиту без аргумента URL в интерактивном терминале (TTY):

```bash
npm start
# или в режиме разработки через tsx:
npm run dev
```

Управление в меню:
- `↑` / `↓` — перемещение по пунктам
- `Enter` — выбор пресета, ввод произвольного URL или переключение языка
- `q` / `Ctrl+C` — безопасный выход с восстановлением курсора и экрана терминала

### 2. Прямой запуск с URL через аргументы CLI

```bash
npm start -- https://speed.cloudflare.com/__down?bytes=10000000
# или с явным флагом:
npm start -- --url https://speed.cloudflare.com/__down?bytes=10000000 --lang en
```

### Поддерживаемые флаги

| Флаг | Описание | По умолчанию |
| --- | --- | --- |
| `-u, --url <url>` | Целевой `http://` или `https://` URL (пропускает меню) | — |
| `-c, --config <path>` | Путь к JSON-файлу пресетов | `config/presets.json` |
| `-l, --lang <ru\|en>` | Язык интерфейса | `ru` |
| `--debug` | Печатать полный stack trace при критических ошибках | `false` |
| `-h, --help` | Показать справку | — |

## Конфигурация пресетов (`config/presets.json`)

Файл должен содержать валидный JSON-массив объектов формата `{ "name": string, "url": string }`:

```json
[
  {
    "name": "Cloudflare Speed Test (10 MB)",
    "url": "https://speed.cloudflare.com/__down?bytes=10000000"
  },
  {
    "name": "Hetzner Ashburn (10 MB)",
    "url": "https://ash-speed.hetzner.com/10MB.bin"
  }
]
```

Все URL проходят проверку на непустоту, синтаксическую корректность и допустимый протокол (`http:` / `https:`).

## Обоснование единиц измерения скорости

Утилита вычисляет и отображает скорость в двух взаимодополняющих единицах десятичной системы СИ:

1. **Mbps (мегабиты в секунду, $10^6$ бит/с):**
   $$\text{Mbps} = \frac{\text{bytes} \times 8}{\text{seconds} \times 1\,000\,000}$$
   Является общепринятым отраслевым стандартом для измерения пропускной способности сетевых каналов и тарифов интернет-провайдеров.
2. **MB/s (мегабайты в секунду, $10^6$ байт/с):**
   $$\text{MB/s} = \frac{\text{bytes}}{\text{seconds} \times 1\,000\,000}$$
   Показывает практическую скорость скачивания файлов, привычную по браузерам и утилитам загрузки.

Использование десятичной базы ($10^6$), а не двоичной ($\text{MiB/s}, 2^{20}$), соответствует стандарту сетевых измерений (Mbps/Gbps) и упрощает прямое сопоставление значений ($1\text{ MB/s} = 8\text{ Mbps}$).

## Обзор архитектуры

Проект построен по принципам SOLID и Dependency Injection со строгим разделением слоев:

- `src/config/` — загрузка JSON-конфига пресетов (`JsonConfigLoader`) и валидация URL (`UrlValidator`).
- `src/network/` — потоковый HTTP(S)-клиент (`NodeHttpStreamClient`) и композитная политика повторов (`RetryPolicy`) на базе паттерна **Strategy** (`RateLimit429Strategy`, `TransientErrorStrategy`).
- `src/core/` — движок замера (`BenchmarkEngine`) с паттерном **Observer** для проброса событий прогресса в UI и чистые функции расчета метрик (`metrics-calculator.ts`).
- `src/i18n/` — типобезопасные словари локализации (`ru`, `en`) и сервис подстановки параметров (`I18nService`).
- `src/tui/` — виртуальный буфер экрана (`ScreenBuffer`), дифференциальный рендерер (`DiffRenderer`), контроллер ввода (`InputController`), управление жизненным циклом терминала (`TerminalLifecycle`) и экраны (`tui-views.ts`).
- `src/app/` — парсинг аргументов (`cli-parser.ts`), координация сценариев (`Application`) и `GlobalErrorBoundary`.
